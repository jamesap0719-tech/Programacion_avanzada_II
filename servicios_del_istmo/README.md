Propósito de esta primera versión.
    creación de una paguina web para que la empresa Servicios del Istmo pueda mostrar sus servicios para captar mas clientes.

Descripción de cada archivo.
    Destro de la carpeta servicios_del_istmo encontrara los siguientes archivos.

    index.php : que contiene todo la estructura de la paguina web.
    cebecera.php : contiene la organizacion de una barra de barra de nevegación. 
    pie.php : contiene la organizacion del pie de paguina para ser contactado.
    style.css : contiene el estilo de la paguina web.
        5 imagenes: 
            1 logo de la empresa
            1 imagen de portada
            1 imagen de redes
            1 imagen de mantenimienti
            1 imagen de desarrollo

Instrucciones y comando para ejecutarlo.
    se a proporcionado un archivo Zip, el cual se tiene que descomprir.
    ejecutarlas 
    abrir: php -S localhost:8000 -t servicios_del_istmo
    le saldra una pestaña "abrir en el navegador".

Resultados de las cuatro comprobaciones.

        2) se cambio el lema de paguina, aparece sin error
        3) cambio del echo, aparece sin error
        4) sin error en la terminal, todo en orden
